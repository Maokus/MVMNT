# @mvmnt-app/plugin-contract

Shared manifest validation primitives for the MVMNT plugin generator and command-line tools. Most
plugin authors do not install this package directly; generated projects receive it transitively
through `create-mvmnt-plugin` and `@mvmnt-app/plugin-tools`.

The public plugin authoring API is provided by
[`@mvmnt-app/plugin-sdk`](https://www.npmjs.com/package/@mvmnt-app/plugin-sdk).
